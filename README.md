# Catholic Quiz App

Este projeto é um web app de quiz católico feito com React, Vite e Material UI.

## Funcionalidades
- Perguntas de múltipla escolha sobre temas católicos
- Placar e feedback imediato após cada resposta
- Interface responsiva e acessível usando Material UI

## Como rodar o projeto

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Rode o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Acesse o app em `http://localhost:5173`

## Estrutura do projeto
- `src/App.tsx`: Componente principal do quiz
- `.github/copilot-instructions.md`: Instruções para geração de código
